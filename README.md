# کو — وسایلم کجاست؟

اپ سادهٔ فارسی برای اینکه بدانی هر وسیله (کابل، شارژر، هندزفری، پاوربانک…) کجاست.
بدون سرور: داده‌ها اول روی گوشی، و با ورود گوگل در یک فایل `koo-data.json` داخل Google Drive خودت.

**نسخهٔ زنده:** https://kooo-app.github.io/

## چه چیزی الان کار می‌کند

- **راه‌اندازی بدون فرم‌بازی:** یکی از قالب‌های آماده را انتخاب می‌کنی و فضاها و جاها همان لحظه ساخته می‌شوند.
  - آپارتمان ۱ خوابه، آپارتمان ۲-۳ خوابه، ویلا/حیاط‌دار، خوابگاه/اتاق اجاره‌ای، ماشین + کیف + دفتر، از صفر.
- **درخت سادهٔ مکان:** `فضا › جا` (مثلاً «آشپزخانه › کابینت بالا»). افزودن، تغییر نام و حذف فضا و جا.
- **ثبت سریع وسیله:** عکس + اسم + دسته‌بندی + فضا + جا + یادداشت.
- **جستجوی فوری:** تایپ می‌کنی «کابل» و می‌بینی کجاست؛ فیلتر دسته و فضا هم دارد.
- **چند وسیله در یک عکس:** از یک قفسه، جعبه یا لوازم یدکی خودرو عکس می‌گیری؛ کو فهرست وسایل را در **یک فرم** می‌آورد (اسم و دسته هر قلم قابل ویرایش، با تیک انتخاب). فضا و جا را یک‌بار می‌گذاری و همه با هم ثبت می‌شوند، اما هر کدام **یک وسیلهٔ جدا و قابل جستجو** است.
- **تشخیص وسیله از عکس با Gemini:** کلید رایگان خودت (BYOK)، دو مسیر موازی (گوگل مستقیم و پل ورسل) با fallback و پیام خطای صادقانه.
- **همگام‌سازی Google Drive:** یک فایل JSON، ورود گوگل، تمدید بی‌صدا با Cloudflare Worker و مرج آیتم‌به‌آیتم.
- **تم روشن و تاریک:** پیش‌فرض روشن؛ در تنظیمات بین ☀️ روشن، 🌙 تاریک و 🌗 خودکار (پیروی از گوشی) جابه‌جا می‌شوی و انتخاب ذخیره می‌ماند.
- **آفلاین + به‌روزرسانی سریع:** Service Worker شبکه‌اول کار می‌کند؛ نسخهٔ جدید با باز کردن بعدی می‌آید و لازم نیست کش را پاک کنی. نوار «نسخهٔ جدید آماده است» هم با یک دکمه به‌روز می‌کند.

## راه‌اندازی

- **هوش مصنوعی:** از تنظیمات برنامه، کلید Gemini را بگذار. راهنمای تصویری داخل خود برنامه: [`help-gemini.html`](help-gemini.html).
- **همگام‌سازی گوگل:** نیاز به سه چیز دارد: OAuth Client گوگل، یک ورکر کلودفلر و (اختیاری) پل ورسل. همهٔ مراحل در [`SETUP.md`](SETUP.md).

تا وقتی این‌ها تنظیم نشده‌اند، برنامه صادقانه می‌گوید «راه‌اندازی نشده» و کامل آفلاین کار می‌کند.

## ساختار

```
index.html              صفحهٔ اصلی (RTL، فارسی)
help-gemini.html        راهنمای گرفتن کلید Gemini (فارسی/انگلیسی)
css/app.css             استایل (روشن/تاریک، موبایل‌اول)
js/utils.js             ابزارها: localStorage، uid، escape، اعداد فارسی، toast
js/state.js             مدل داده، قالب‌های فضا، merge، اثر انگشت
js/app.js               رابط کاربری: onboarding، وسایل، درخت فضاها، تنظیمات
js/scan.js              Gemini: دو مسیر، fallback مدل، تست اتصال، فشرده‌کردن عکس
js/sync.js              Google Drive: ورود، تمدید توکن، pull/push/merge
tools/api-gemini.js     کد پل ورسل (برای ریپوی جدا koo-api)
worker/koo-sync.js      ورکر کلودفلر تمدید توکن گوگل
tools/harness/          تست‌های ساده (jsdom)
sw.js                   کش آفلاین
```

## انتشار نسخه

```bash
node tools/bump-version.mjs 0.2.1   # هم APP_VERSION و هم CACHE سرویس‌ورکر را بالا می‌برد
git add -A && git commit -m "نسخه 0.2.1" && git push
```

سرویس‌ورکر **شبکه‌اول** است: HTML/JS/CSS همیشه از شبکه با `cache: 'no-store'` خوانده و در پس‌زمینه کش می‌شوند؛ کش فقط برای حالت آفلاین است. نسخهٔ تازه با `skipWaiting` فعال می‌شود و صفحه یک‌بار خودش reload می‌کند. برای همین کاربران بدون پاک‌کردن کش به نسخهٔ جدید می‌رسند.

## تست

```bash
cd tools/harness
npm install
npm test
```

سه دسته تست: رابط کاربری (onboarding، افزودن/جستجو/حذف، درخت فضاها)، منطق داده و مرج، و مسیرهای هوش مصنوعی و همگام‌سازی با fetch ساختگی.
